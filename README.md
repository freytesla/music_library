# music_library
轻量纯前端音乐库管理工具，本地存储数据，无需后端，快速管理个人音乐曲目。

## 在线访问
[https://musicmemo.netlify.app/](https://musicmemo.netlify.app/)

## 核心功能
- 曲目管理：添加、编辑、删除音乐信息，记录歌名、歌手、BPM、风格、情绪等
- 筛选搜索：支持关键词搜索、风格分类筛选
- 收藏标记：可标记喜爱曲目，快速区分偏好
- 数据统计：实时展示曲目总数、平均BPM、风格种类、收藏数量
- 本地存储：数据保存在浏览器，刷新/关闭页面不丢失

## 技术栈
HTML5 + CSS3 + 原生JavaScript(ES6+)、localStorage、响应式设计

## 快速使用
1. 直接访问上述在线链接即可使用
2. 点击添加按钮，填写歌名、歌手等信息完成曲目录入
3. 利用搜索框/风格按钮筛选曲目，点击收藏/删除/编辑按钮完成对应操作
